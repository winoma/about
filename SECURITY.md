# Security Policy

## Supported Versions

This policy covers **WinOma Scan** (`WinOma_Scan.ps1`), the script published in this repository.

| WinOma Scan version | Supported |
| ------------------- | --------- |
| 1.3.x               | :white_check_mark: |
| < 1.3               | :x: |

## Reporting a Vulnerability

If you discover a security issue in any WinOma script or tool, please report it privately rather than opening a public issue:

- **Telegram:** [@omarizzww](https://t.me/omarizzww)

We will review and respond as quickly as possible.
